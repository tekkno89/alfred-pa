# Alfred Triage v3.3 Design Specification

**Goal:** Enhance Alfred's triage system with active hours configuration, refactored setup wizard, message types UI, and transparency features.

**Status:** Design approved, ready for implementation

**Timeline:** 3-4 weeks

---

## Overview

Triage v3.3 adds user-configurable active hours, a refactored LLM-driven setup wizard, full UI for custom message types, and a transparency section to show what Alfred has learned. This update also introduces hybrid priority/action labels and removes the unused digest instructions feature.

### Features

| Feature | Priority |
|---------|----------|
| Active Hours Configuration | High |
| Setup Wizard Refactor | High |
| Message Types UI | High |
| Sensitive Channel Toggle | Medium |
| Hybrid Priority/Action Labels | Medium |
| EOD Review Time Setting | Medium |
| Transparency Section | Medium |
| Remove Digest Instructions | Low |

## Feature 1: Active Hours Configuration

### User Story

As a user, I want to set specific hours when Alfred can deliver triage notifications, so I'm not interrupted outside my working hours.

### Requirements

1. **Per-day windows**: User can set different active hours for each day of the week (Monday-Sunday)
2. **Breakthrough setting**: User chooses whether notify_now messages break through outside active hours
3. **Queue behavior**: Messages received outside active hours are queued for delivery at next active window

### Model Changes

**New model: `ActiveHoursConfig`**

```python
# backend/app/db/models/triage.py

class ActiveHoursConfig(Base):
    """Per-day active hours configuration for triage delivery."""
    __tablename__ = "active_hours_config"

    id: Mapped[UUID] = mapped_column(UUID, primary_key=True, default=uuid4)
    user_id: Mapped[UUID] = mapped_column(UUID, ForeignKey("users.id"), nullable=False)
    day_of_week: Mapped[int] = mapped_column(Integer, nullable=False)  # 0=Monday, 6=Sunday
    start_time: Mapped[str] = mapped_column(String(5), nullable=False)  # "09:00"
    end_time: Mapped[str] = mapped_column(String(5), nullable=False)  # "18:00"
    is_enabled: Mapped[bool] = mapped_column(Boolean, default=True)

    __table_args__ = (
        UniqueConstraint("user_id", "day_of_week", name="uq_active_hours_user_day"),
    )
```

**New field on `TriageUserSettings`:**

```python
active_hours_breakthrough: Mapped[str] = mapped_column(
    String(20), default="allow_notify_now"
)  # "allow_notify_now" | "queue_all"
```

### API Endpoints

```
GET    /api/triage/active-hours          # Get all active hours configs
PUT    /api/triage/active-hours          # Update active hours (batch)
PUT    /api/triage/settings              # Update breakthrough setting
```

### Behavior

**During active hours:**
- Normal delivery: notify_now pushes immediately, summarize_next/summarize_eod queue for digest

**Outside active hours:**
- If `breakthrough == "allow_notify_now"`:
  - notify_now (P0) messages still push immediately
  - summarize_next/summarize_eod queue until next active window
- If `breakthrough == "queue_all"`:
  - All messages queue until next active window

**At start of active hours:**
- Deliver any queued messages via digest

### Requirements

1. Users can create, edit, and delete message types

4. Message types are suggested by the wizard and can be added manually

```
GET /api/triage/transparency

# Response
class TransparencyData(BaseModel):
    keywords: list[KeywordData]
    sender_patterns: list[SenderPatternData]
    recent_corrections: list[CorrectionData]

class KeywordData(BaseModel):
    keyword: str
    weight: float
    source_category: str  # "public", "sensitive", "dm"

class SenderPatternData(BaseModel):
    sender_name: str
    sender_slack_id: str
    channel_name: str
    action_distribution: dict[str, float]
    sample_count: int

class CorrectionData(BaseModel):
    message_text: str  # Truncated to 50 chars
    corrected_action: str
    created_at: datetime
```
